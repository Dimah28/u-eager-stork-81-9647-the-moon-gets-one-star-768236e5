`main.py` (Python 3.13, stdlib only, no network) writes one one-star review
of the Moon, at most 120 characters, to `/output/entry.txt`:

"★☆☆☆☆ It drags the ocean around twice a day, wakes my dog at 3 a.m., and never once apologized. Would not orbit again."

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
